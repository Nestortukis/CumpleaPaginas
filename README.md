# 💙 24 vueltas al sol

Página de cumpleaños responsive hecha con HTML, CSS y JavaScript.

## Personalizar

### 1. Spotify
En `index.html`, busca:

`https://open.spotify.com/`

y reemplázalo por el enlace de la canción que quieras.

### 2. Fotos
Coloca tus imágenes en `img/` con estos nombres:

- foto1.jpg
- foto2.jpg
- foto3.jpg
- foto4.jpg

### 3. 24 razones
En `script.js`, modifica:

`const reasons = [`

Puedes escribir tus propias 24 razones.

### 4. Carta
En `index.html`, busca:

`<!-- ESCRIBE AQUÍ TU CARTA -->`

y reemplaza el texto por tu carta.

## GitHub Pages

Sube todos los archivos al repositorio, luego ve a:

Settings → Pages → Deploy from a branch → main → / (root)

No necesita servidor.
